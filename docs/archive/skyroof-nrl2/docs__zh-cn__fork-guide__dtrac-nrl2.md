# DTrac RC-3040S NRL2（实验性功能）

在 **设置 → 旋转器控制** 中选择 **Controller Driver: Native**、**Native Protocol: DtracNrl2**，程序自动选择 UDP。填写兼容的 NRL2 中继地址和端口、14 位十六进制 RotorID、持久保存的 14 位 APP SID。

RotorID 的编辑器通过局域网 UDP 60059 广播 `cmd=ping\n` 发现控制板；这与 NRL2 远端服务器不是同一地址。局域网 TCP GS-232 控制通常使用 60020 端口。DTrac 方言使用 48 字节头、两个 7 字节标识、Type 5 和两位 ASCII 长度，与通用 nrllink 服务端的协议不完全兼容。

支持 `C2\r\n` 位置查询、`W### ###\r\n` 定位、`S\r\n` 停止及手动方向控制。收到与目标及客户端 ID 匹配的新鲜角度反馈前，默认禁止移动。

**PARK**：打开“DTrac Single Target PARK”后，使用固件原生 W 目标定位到保存的 PARK 坐标。不是机械寻零或编码器重新校准。自动加减速由控制板固件执行。

**DEMO**：在旋转器手动控制卡片选择 **NRL2...**，进入独立操作窗口。起始/终止 AZ、EL、步进、停留时间和循环次数在旋转器设置中配置。巡航由 SkyRoof 闭环管理，不能冒称已经实现固件 `AT+TEST`。STOP、角度反馈超时、跟踪切换或到位超时均会中止巡航。

**重启**：先 STOP，再尝试实验性 `AT+RESET\r\n`，必须二次确认。是否能通过 Type 5 被远端固件接受尚未经过实机验证。重启后保持安全锁，重新检查云台及应用设置。

注意：尚未完成 DTrac 公网中继与真实云台的端到端验收。UDP 发包成功不等于电机已安全停止；应保留机械限位及物理急停。
